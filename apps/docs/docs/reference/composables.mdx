## rememberFoldState

```kotlin
@Composable
public fun rememberFoldState(): FoldState
```

The current `FoldState`, updated as the device folds and unfolds. It returns the state of the nearest `ProvideFoldState` when there is one, otherwise the state the platform reports. JVM and wasm report `FoldState.None`.

## rememberHinge

```kotlin
@Composable
public fun rememberHinge(): Hinge?
```

The current `Hinge`, or `null`. Shorthand for `rememberFoldState().hinge`.

## rememberFoldStateFlow

```kotlin
@Composable
public fun rememberFoldStateFlow(): StateFlow<FoldState>
```

The current `FoldState` as a `StateFlow`, for a view-model or other code outside composition. It follows `rememberFoldState()` and has the current state from the first read. It updates only while the call is in the composition, then keeps its last value. See [observing the fold](/guides/observing-the-fold).

## postures

```kotlin
public fun StateFlow<FoldState>.postures(): Flow<Posture>
```

The `Posture` of each state: the current one first, then only when it changes. A change of hinge angle within a posture emits nothing.

## rememberPostureTransition

```kotlin
@Composable
public fun rememberPostureTransition(): PostureTransition
```

| Property | Description |
| --- | --- |
| `previous` | The posture before the latest change. Equal to `current` until the posture first changes. |
| `current` | The current posture. |
| `changed` | Whether the posture has changed since the composition began. |

Recomposes when the posture changes, not when only the hinge angle does.

## ProvideFoldState

```kotlin
@Composable
public fun ProvideFoldState(state: FoldState, content: @Composable () -> Unit)
```

| Parameter | Description |
| --- | --- |
| `state` | The state `rememberFoldState()` returns inside `content`. |
| `content` | The content that reads it. |

For previews, tests and simulators.

## FoldAwareTwoPane

```kotlin
@Composable
public fun FoldAwareTwoPane(
    first: @Composable () -> Unit,
    second: @Composable () -> Unit,
    modifier: Modifier = Modifier,
    fallback: TwoPaneFallback = TwoPaneFallback.FirstOnly,
)
```

| Parameter | Description |
| --- | --- |
| `first` | The left pane across a vertical fold, the top pane across a horizontal one. |
| `second` | The right or bottom pane. |
| `modifier` | Applied to the layout. |
| `fallback` | What to show when no separating fold crosses the layout. |

With a separating fold the panes split exactly at the fold, and skip its bounds when `isOccluding`. See [two-pane layouts](/guides/two-pane-layouts).

## TabletopLayout

```kotlin
@Composable
public fun TabletopLayout(
    top: @Composable () -> Unit,
    bottom: @Composable () -> Unit,
    modifier: Modifier = Modifier,
    flat: @Composable () -> Unit = top,
)
```

| Parameter | Description |
| --- | --- |
| `top` | Shown above the fold in `Posture.Tabletop`. |
| `bottom` | Shown below the fold in `Posture.Tabletop`. |
| `modifier` | Applied to the layout. |
| `flat` | Shown in every other posture. Defaults to `top`. |

See [tabletop mode](/guides/tabletop-mode).

## Modifier.avoidFold

```kotlin
public fun Modifier.avoidFold(): Modifier
```

When a separating fold crosses the element, the element keeps its place in the layout and draws its content on the larger side of the fold. Otherwise nothing changes. See [avoiding the fold](/guides/avoiding-the-fold).

## rememberCoverDisplayState

Package `com.jantursky.crease.cover`, artifact `crease-cover`.

```kotlin
@Composable
public fun rememberCoverDisplayState(): CoverDisplayState
```

The current `CoverDisplayState`, updated as the system allows or withdraws the outer display. It returns the state of the nearest `ProvideCoverDisplayState` when there is one, otherwise the state the platform reports. JVM and wasm report `Unsupported`. See the [cover display guide](/guides/cover-display).

## ProvideCoverDisplayState

```kotlin
@Composable
public fun ProvideCoverDisplayState(state: CoverDisplayState, content: @Composable () -> Unit)
```

Makes `rememberCoverDisplayState()` return `state` inside `content`. Use it for previews, tests and simulators. A `CoverDisplay` inside it composes nothing, since there is no outer display to show it on.

## CoverDisplay

```kotlin
@Composable
public fun CoverDisplay(enabled: Boolean = true, content: @Composable () -> Unit)
```

Shows `content` on the outer display while `enabled` is true and the system allows it. The content leaves the composition of the call site: it is composed on the outer display, in a window of its own, and only while the state is `Available` or `Active`. Where that is never the case, nothing is composed.

## rememberCameraDirections

```kotlin
@Composable
public fun rememberCameraDirections(): CameraDirections?
```

The directions of the cameras relative to the display this composable is on, or `null` where the platform cannot tell. Only iOS 27.1 can. On iOS the lists are empty until the system has reported once.

## ProvideCameraDirections

```kotlin
@Composable
public fun ProvideCameraDirections(directions: CameraDirections?, content: @Composable () -> Unit)
```

Makes `rememberCameraDirections()` return `directions` inside `content`. Use it for previews and tests.

## setContentWithFold

Package `com.jantursky.crease.test`, artifact `crease-test`.

public fun ComposeUiTest.setContentWithFold(
    state: FoldState = FoldState.None,
    content: @Composable () -> Unit,

## rememberWindowAdaptiveInfo

Package `com.jantursky.crease.adaptive`, artifact `crease-adaptive`.

```kotlin
@Composable
public fun rememberWindowAdaptiveInfo(): WindowAdaptiveInfo
```

Window adaptive info whose size class is the one `currentWindowAdaptiveInfoV2()` computes for the window and whose posture comes from `rememberFoldState()`. Inside this call Crease's posture replaces the adaptive library's own. See [Material3 adaptive](/guides/material3-adaptive).

## rememberFoldLayoutClass

```kotlin
@Composable
public fun rememberFoldLayoutClass(): FoldLayoutClass
```

The current `FoldLayoutClass`. It is recomputed when the window size class or the posture changes, and the two change independently.

## toWindowPosture

```kotlin
public fun FoldState.toWindowPosture(): androidx.compose.material3.adaptive.Posture
```

Converts a fold state to the Material3 adaptive library's posture. The posture is tabletop when `FoldState.posture` is `Tabletop`, and each fold becomes one hinge with the same bounds, orientation, separating and occluding flags. A hinge counts as flat when the device reports it fully open.
